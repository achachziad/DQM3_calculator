# Data

Two sources:

| Source | Content | Location | License | Versioned |
|---|---|---|---|---|
| [MetalKid/DQM3_Database](https://github.com/MetalKid/DQM3_Database) | Everything (EN, JA, **FR monster names only**) | `data/` (git submodule) | MIT, credit requested | yes (submodule pointer) |
| [wikidragonquest.fr](https://wikidragonquest.fr) | **FR talent names** + their tiers | `data-fr/` (generated by `dqm3-import`) | **not stated** | **no** (`.gitignore`) |

## 1. MetalKid (`data/data/json/`)

The repository is ~553 MB, almost entirely images. Only the JSON matters:
**46 files, ~3.7 MB** → embedding with `include_str!` is fine.

- `raw/`: one file per SQL table, linked by integer ids (`MonsterId`,
  `TalentId`…). **This is what we load.**
- `computed/`: denormalised views (by name). Verified equal to `raw/`
  (see §1.6); not used, `raw/` is the source of truth.
- `reference/`: progression data (`EventMonsters`, `LocationProgression`,
  `EggGradeUnlock`).

Files are UTF-8 **with BOM**: strip `\u{feff}` before `serde_json`.

### 1.1 Monsters — `raw/Monster.json` (606 rows)

| Field | Notes |
|---|---|
| `MonsterId` | primary key (≠ in-game number) |
| `Number` | in-game number 1–526, no gaps; **`null` = placeholder** (see below) |
| `Name` / `FrenchName` / `JapaneseName` | EN always set; FR missing for 3 monsters |
| `FamilyId` → `Family.json` (8), `RankId` → `Rank.json` (10) | |
| `HP`…`Wis`, `MaxHP`…`MaxWis` | null only for placeholders |
| `EggTypeId` | nullable |

**Placeholders**: the 80 rows with `Number = null` are not monsters but
synthesis rules "any monster of family F and rank R", named
`<Family> Family (<Rank>)`, e.g. `Slime Family (G)`, `Beast Family (Any)`.
The `??? Family` ones are never used in recipes.

**French names**: 523/526. Missing: Triple Splatty, Flurry Fiend,
Mimic with Cheese (expired events, see `reference/EventMonsters.json`).
134 contain non-ASCII letters: `à â è é ê î ï ô û œ É Â` (`œ` must be
handled by accent-insensitive search). No collision between FR names,
even accent-stripped, nor with another monster's EN name. 27 monsters have
FR = EN.

Ranks: `G F E D C B A S X` + `Any` (rank wildcard for placeholders).

### 1.2 Recipes — `raw/MonsterSynthesis.json` (714 rows)

`MonsterResultId` + either 2 parents **or** 4 grandparents (never both):

| Kind | Count | Fields |
|---|---|---|
| monster + monster | 433 | `MonsterParent1Id`, `MonsterParent2Id` |
| with a family placeholder | 252 both sides + 35 one side | same fields, parent = placeholder |
| 4 grandparents (bosses: Zoma, Estark…) | 19 | `MonsterGrandParent{1A,1B,2A,2B}Id` |

- Family + family rules always use the same rank on both sides; the result
  has that rank (251/252).
- `AreBothRankSpecific`: true on a single row (Feralball); meaning unclear.
- 504 monsters have ≥ 1 recipe (max 4). **22 have none**: egg-only (most),
  Slime and Metal Slime (wild), 3 event monsters, and **Fuzzy (no known
  source in the data)**.

### 1.3 Talents

| File | Content |
|---|---|
| `Talent.json` (241) | `Name`, `JapaneseName`, `IsEggOnly` (3 talents). **No French.** |
| `TalentSkill.json` | `TalentId`, `SkillId`, `Points`: skill unlocked at N points |
| `TalentTrait.json` | `TalentId`, `TraitId`, `Points`: trait unlocked at N points |
| `MonsterTalent.json` | `MonsterId`, `TalentId`, `IsPrimary` |
| `TalentSynthesis.json` + `TalentSynthesisTalent.json` | talent evolution |

- **Tiers** = `TalentSkill` ∪ `TalentTrait`. Each tier unlocks exactly one
  skill *or* one trait (never two rewards at the same points).
- **Fixed vs random**: `IsPrimary = true` is the fixed talent, others are
  random. Source anomalies: Rubble Slime has 2 primaries; Fromage Fray and
  Ursa Mega have none.
- **Evolution**: a `TalentSynthesis` row gives the result; its 1 or 2
  ingredients are in `TalentSynthesisTalent`.
  1 ingredient = upgrade (Chilly Receptionist → Frosty Receptionist);
  2 = combination (Spicy Slasher + Blowy Slasher → Air Fryer).
  A talent can have several recipes (Polariser: 10).

### 1.4 Other tables

`MonsterTrait` (with `SizeId` and `UnlockLevel`), `Trait`, `Skill`,
`MonsterResistance`, `MonsterLocation` (`LocationId`, `SeasonId`,
`WeatherId`, `IsMiniBoss`), `Location`, `Season` (4), `Weather`
(Sun / Precipitation), `Size` (2), items and eggs.
Only 213 monsters are found in the wild.

### 1.5 Integrity

0 broken foreign keys over all checked relations (synthesis, talents,
traits, skills, locations). No duplicate recipes, numbers or names.
Typo in the source: `Prism peacock` (lowercase).

### 1.6 `computed/` vs `raw/`

| File | Result |
|---|---|
| `Syntheses.json` | identical (714/714) |
| `MonsterLocations.json` | lossless: seasons × weathers grouping is always a full cross product (469 groups) |
| `Talents.json` | equivalent, but 2-ingredient parents are strings `"A + B"` |

## 2. French talents (`data-fr/`, generated)

MetalKid has no French talent names. They are imported from
wikidragonquest.fr by **`crates/dqm3-import`**, a separate binary run
**by hand only** (`cargo run -p dqm3-import`). Its network dependency
(`ureq`) never enters `dqm3-core` or `dqm3-gui`.

### 2.1 How it works

- MediaWiki API `https://wikidragonquest.fr/api.php` (not HTML).
- **Source of the talent list**: the page
  `Liste des talents de Dragon Quest Monsters 3` (241 rows = MetalKid's
  241 talents; 189 "Compétence", 52 "Bonus de caractéristique").
  The category `Talent de Dragon Quest Monsters 3` is **not** used: only
  71 pages, and it contains noise (a monster page).
- The **in-game FR name is the list label**, not the page title: many
  entries are redirects to a page named after another game
  (`Espoir de Flamme` → page `Apprenti de Flamme`). Confirmed in game.
- Linked pages are fetched by title, **10 per request** (50 was too heavy
  for the host), with `redirects=1` and `prop=revisions|langlinks|info`
  (≈ 26 requests in total, ≈ 5 min).
- Politeness: **≥ 10 s between requests**, explicit User-Agent, up to 4
  attempts with waits of 30, 60, 120 s on overload, then stop (progress
  stays cached; run again later). The host is a shared server that
  often answers **508 Resource Limit Is Reached** or HTTP 200 +
  `DBConnectionError`; both are retried.
- Cache: every valid response in `data-fr/cache/` (delete it to refresh).

### 2.2 Wikitext format

A page can cover several games; only the table under the
`Dragon Quest Monsters 3` heading (`===X===` or `=== X ===`) is read:

```
{| class="standard ccompetence"
!Points !Nom !Description
|-
|<center>3</center>||<center>[[Crève-cœur]]</center>||''…''
```

Cells may lack `<center>`, be one per line, or be links with a label
(`[[Premiers secours|1ers secours]]`). **Traits** appear in the same table
without a link (`PV max. +4`). Titles may carry a disambiguation suffix,
removed: `Soigneur (compétence)` → `Soigneur`.

List page rows: `|<center>Type</center>||<center>[[Target|Name]]</center>`.
Special cases: labelled links (21, e.g. `[[Soigneur (compétence)|Soigneur]]`),
a link to a section (`[[Estark (boss)#Talent|Estark]]`: the talent table
is under the `Talent` heading of the boss page), and the name `Tourmenteur`
used by two different entries.

English name: the `en` interlanguage link, else the intro sentence
(`''Frizz Afficionado'' en anglais`), disambiguation suffix removed.

### 2.3 Output

`data-fr/talents.json`:

```json
{ "en": "Frizz Afficionado", "fr": "Espoir de Flamme",
  "fr_page": "Apprenti de Flamme", "ja": "…",
  … }
{ "en": "Assassin", "fr": "Assassin", "fr_page": null, "ja": "アサシン",
  "thresholds": [3, 10, 20, 30, 50, 70, 85, 100],
  "skills_fr": ["Crève-cœur", "Tempête de sable", …],
  "source_url": "https://wikidragonquest.fr/…" }
```

- Matching with MetalKid on the **English** name (case-insensitive,
  `’` = `'`); `en` uses MetalKid's spelling, `ja` comes from MetalKid.
- `fr_page`: the page title when it differs from `fr` (often the DQM4
  name), kept as a search alias; `null` otherwise.
- `skills_fr` holds skills **and** traits, same order as `thresholds`.
- Unmatched entries are kept with `ja: null` (`en: null` if unknown).

`data-fr/report.md`: matches OK / different thresholds / MetalKid talents
without FR match / FR talents without EN match (page missing, no EN name,
or EN name unknown to MetalKid).

### 2.4 Manual corrections (`crates/dqm3-import/src/manual.rs`)

Applied after the automatic import, each one listed in the report:

- **English names** (10), keyed by list target: wiki typos/short names
  (`Soothesayer`, `Dragonlord`, `Psaro`…), pages without EN name, and
  missing pages. Note: the game really has **two talents named
  "Tourmenteur"**: Storm Brewer (page `Tourmenteur`) and Doomsayer
  (page `Tourmenteur ( )`, missing). Checked in game on Grouillâme.
- **Tiers read in game**: Doomsayer (all 10, no wiki page) and Protector /
  Bon génie (tier 150 "Réflexion", missing on the wiki). They only fill
  missing points, never replace wiki data.

### 2.5 Result (import of 2026-11-19)

All **241 talents** have a French name and a MetalKid match.
**239** have exactly MetalKid's thresholds. The 2 others, Parangon
(Paragon) and Gros bras (Musclehead), have no wiki page: FR talent name
known, FR skill names unknown (can be added to `manual.rs` from an
in-game screenshot).

### 2.6 Known limits

- Wiki license not stated → `data-fr/` is git-ignored and not embedded
  until clarified.
- See `data-fr/report.md` after each import for the actual coverage.
